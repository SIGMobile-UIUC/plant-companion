## Delivered implementation

- Production XIAO ESP32-C3 firmware in [PlantCompanion.ino](../firmware/PlantCompanion/PlantCompanion.ino), with shared [pc_core.h](../firmware/PlantCompanion/pc_core.h). Bounded USB startup, independent 20-minute monotonic sampling, request-matched manual acquisition, isolated sensor validity, NVS calibration/identity and a CRC-protected persistent 1024-slot ring. Original diagnostic rollback is unchanged.
- Native Android/iOS foreground BLE transport and sync in [app/lib/ble](../app/lib/ble/), using the existing PlantStore/forms/details flow. Physical discovery and connection are staged until Save. Assignment persists by firmware identity; platform identifiers are hints verified on every connection. Launch/resume reconnects and a foreground poll catches up device-side recordings. Web/desktop keep simulation and explain mobile-only physical BLE.
- Additive SQLite v3 migration in [app_database.dart](../app/lib/persistence/app_database.dart) and transactional physical imports in [ble_persistence.dart](../app/lib/persistence/ble_persistence.dart). Complete batches commit before ACK; pending Refresh identity survives failure. Latest data and history cursors are independent. Sequence/generation ordering prevents older imports from replacing the latest reading. Reassignment fences old ownership and rejects stale in-flight packets.
- Existing Florence cards, units, condition logic, portraits and sensor rails receive real values through normal repository reads. The Companion Device card/Home badge identify physical BLE; a small inline history expander shows source, kind, sequence and known/unknown measurement time. Simulator acquisition, scheduling and commits reject physical devices. Failed post-save acquisition or cleanup cannot undo a saved plant; secondary cleanup failures after Save/Delete become warnings.
- [Protocol reference](ble-protocol.md), [exact flash/calibration/iPhone runbook and one ordered hardware checklist](phase-g-hardware-runbook.md), shared [C++-generated wire fixtures](../protocol/golden-v1.json), [host firmware tests](../firmware/test/core_test.cpp), [byte-level peripheral tests](../app/test/ble_integration_test.dart), and a [populated v2 migration test](../app/test/ble_migration_test.dart).

No BLE background service, battery feature, calibration screen, simultaneous device manager or Phase B-style visual redesign was added. `SIGmobile_Plant_Monitor_Plan.md` was not found in the supplied checkout/targeted local search; the actual code and supplied current brief governed this integration.
